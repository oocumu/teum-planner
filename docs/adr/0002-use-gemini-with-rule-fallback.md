# ADR-0002: Gemini 무료 API를 쓰고 규칙 기반 파서로 대체한다

- 상태: Accepted
- 날짜: 2026-11-15

## 배경

자유 입력을 일정으로 정리하려면 한국어 이해가 필요하지만, 개인 프로젝트라 유료 API 비용을 쓰기 어렵다. GitHub Pages 배포본에는 서버가 없어 API 키를 둘 수 없다.

## 선택지

| 선택지 | 장점 | 단점 |
|---|---|---|
| Gemini 무료 API만 사용 | 품질 양호, 무료 할당량 | 호출 한도, 정적 배포 불가 |
| 유료 LLM API | 안정적 | 비용 |
| 규칙 기반 파서만 사용 | 비용·한도 없음, 브라우저에서 실행 가능 | 표현 범위 제한 |

## 결정

서버에 `GEMINI_API_KEY`가 있으면 Gemini를 호출하고, 키가 없거나 호출이 실패하면 규칙 기반 파서(`src/parser.js`)를 사용한다. 정적 배포본은 규칙 기반으로만 동작한다.

## 결과

API 장애나 한도 초과에도 서비스가 동작한다. 두 경로의 출력 형식을 맞추기 위해 `normalize()`로 AI 응답을 검증한다.
