# ADR-0003: 프로토타입은 의존성 없는 Node.js로 작성한다

- 상태: Accepted
- 날짜: 2026-11-15
- 관련: README 5. 기술 스택

## 배경

제안서의 목표 스택은 Next.js + TypeScript + Supabase + Vitest이다. 중간 점검(8주차) 전까지는 파싱과 스케줄링 알고리즘을 먼저 검증하고, CI 파이프라인을 갖춰야 한다.

## 선택지

| 선택지 | 장점 | 단점 |
|---|---|---|
| 처음부터 Next.js로 구현 | 최종 구조와 동일 | 화면·DB 설정에 시간이 들어 알고리즘 검증이 늦어짐 |
| 순수 Node.js(ESM) + node:test | 의존성이 적어 CI가 빠르고, 같은 코드를 브라우저에서도 실행 가능 | 이후 이전 작업 필요 |

## 결정

`src/parser.js`, `src/scheduler.js`를 의존성 없는 ES 모듈로 작성하고 `node:test`로 테스트한다. 9주차 이후 Next.js로 옮길 때 두 모듈은 그대로 가져가고 타입만 추가한다.

## 결과

정적 페이지(GitHub Pages)에서도 동작하는 데모를 바로 배포할 수 있다. Next.js 이전 시점에 테스트 러너를 Vitest로 바꾸는 ADR을 새로 작성한다.
