# ADR-0001: 기술 결정을 ADR로 기록한다

- 상태: Accepted
- 날짜: 2026-11-15

## 배경

16주 동안 기술 선택이 여러 번 이루어지며, 결정 이유가 커밋과 대화 기록에 흩어지면 나중에 추적하기 어렵다.

## 선택지

| 선택지 | 장점 | 단점 |
|---|---|---|
| 기록하지 않음 | 수고 없음 | 결정 이유 유실 |
| Wiki에 정리 | 수정이 쉬움 | 코드와 버전이 분리됨 |
| `docs/adr/`에 Markdown | 코드와 함께 버전 관리, PR 리뷰 가능 | 파일 증가 |

## 결정

`docs/adr/`에 경량 ADR(Nygard 형식)을 작성한다.

## 결과

결정과 코드 변경이 같은 PR로 리뷰된다. RFC 토론의 결론은 ADR로 옮긴다.
